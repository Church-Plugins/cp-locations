# Getting Help

This guide covers the support channels and resources available for CP Locations.

## Documentation

Start with the documentation for answers to common questions:

- [FAQ](faq.md) — Frequently asked questions
- [Troubleshooting](../advanced/troubleshooting.md) — Common issues and solutions
- [Settings](../features/settings.md) — Plugin configuration reference

## Support Portal

For issues not covered in the documentation, contact support through the ChurchPlugins support portal:

1. Visit [churchplugins.com/support](https://churchplugins.com/support)
2. Submit a support ticket describing your issue
3. Include the following details:
   - WordPress version
   - CP Locations version
   - A description of the problem
   - Steps to reproduce the issue
   - Any error messages or screenshots

Support is for license holders.

## Community Resources

- **ChurchPlugins Website** — [churchplugins.com](https://churchplugins.com) for product updates, tutorials, and blog posts

## Before Contacting Support

To help resolve your issue quickly:

1. **Check the documentation** — Many common questions are answered in the [FAQ](faq.md) and [Troubleshooting](../advanced/troubleshooting.md) guides
2. **Update to the latest version** — Ensure CP Locations and WordPress are up to date
3. **Test for plugin conflicts** — Temporarily deactivate other plugins to see if the issue persists
4. **Check browser console** — For frontend issues, open the browser developer console (F12) and note any errors
5. **Test the REST API** — Visit `https://yoursite.com/wp-json/cp-locations/v1/locations` to verify the API is accessible
